# Ramayan Bhakti Video Skill

Kaise use kare:
1. `ramayan-bhakti-video/` folder ko apne agent (Claude Code: `.claude/skills/`, ya project root) me rakhein. `AGENTS.md` / `SKILL.md` dono entry points hain.
2. Agent ko apni **script** do: "is script ka visual plan banao".
3. Agent `shot_list.md` dega – har beat ka scene, characters, camera, animation, text, image prompt.

Characters fixed hai; scene/visual har script ke hisaab se naya banta hai.
