# Art Style Guide (consistent across all videos – this is the "look", not the scenes)

## Core look (from reference video)
- **Flat 2D vector / paper-cutout puppet animation.** Layered pieces with a faint soft drop-shadow giving papercraft depth. Thin dark-brown outlines on characters.
- **Indian folk ornament:** gold borders, rangoli dots, Madhubani/Rajasthani floral motifs, temple arches, jali windows, diyas, torans, flags.
- **Gold is the signature accent** (jewellery, frames, text outlines).
- **Characters sit in front of simple, richly coloured, layered backgrounds** (3–4 depth layers: sky/light → far shapes → mid architecture/trees → ground).
- **Glow & light:** sun-disc/moon-disc, light rays, soft vignette, sparkles, floating particles (petals, embers, confetti, stars).

## Background vocabulary (pick per script, don't reuse blindly)
| Mood / ras | Palette idea | Elements |
|---|---|---|
| Shant / dawn / hope | peach–gold sky, pale green hills | sun disc, birds, soft rays |
| Bhakti / night prayer | deep teal/indigo + gold | stars, crescent moon, diyas, floating petals |
| Veer / battle | saffron–red, purple mountains | flags, arrows, dust, banner rows |
| Karun / separation | dusk orange → violet, rain streaks | lone tree, empty hut, slow zoom |
| Raudra / Lanka | black, ember red, fire orange | jagged flames, fort silhouettes (stylised) |
| Adbhut / divine | royal blue sunburst rays + gold | halo ring, lotus, glow burst |
| Forest / vanvaas | layered greens, sun beams | leaf frames in corners, birds |
| Palace / Ayodhya | maroon + gold arches, patterned floor | diyas, columns with dots, curtains |
| Sea / Setu | turquoise wavy lines, golden sunset | floating stones, waves |

## Colour rules
- Keep **3–4 dominant colours per scene** + gold accent.
- Ram scenes lean **blue/gold/saffron**; Ravan/Lanka lean **red/black/ember**; forest **green/yellow**; night prayer **teal/indigo**.
- Never put a blue-skinned character on a blue background without a rim light/halo/contrasting shape.
- Colour changes *must* follow emotion changes in the script.

## Typography / on-screen text
- **Devanagari display font** (bold, calligraphic, gold-yellow with dark outline/shadow) for chapter titles and key words (e.g. "वचन", "प्रेम", "युद्ध", "शिक्षा").
- Small English/Hinglish sub-label under in clean sans, spaced caps.
- **Name ribbons:** small ribbon banner above characters (red ribbon for Ram, teal for Krishna, gold/orange for sages) – use for first appearance of each character.
- **Subtitles:** bottom centre, white bold sans with black outline, **current spoken word highlighted in yellow**.
- **Chapter card:** dark navy/purple panel with ornate gold border + corner ornaments, small chapter label, big Devanagari word, tiny English translation; bow icon left & flute/other motif right (change motif to match the script, e.g. lotus / diya / paduka).
- Keep text inside safe margins (5% edges; 15% bottom for subtitles in 9:16).

## Motion language (cut-out animation)
- Characters animate by **joint rotation**: arm raise, head tilt, slight breathing bob, blink. No realistic morphing.
- Entrance: slide + soft ease-out / pop-scale; exit: fade or slide.
- Camera: slow push-in on emotional lines; slow pan on wide establishing shots; parallax between layers.
- Effects: rays rotating slowly, particles drifting, flames flickering (loop), water lines moving, stars twinkling.
- Transitions: crossfade, golden-light flash, page/curtain wipe, shape-wipe (diya/lotus), match-cut on a prop. Avoid fast glitch/zoom cuts – bhakti mood = smooth.
- Beat length 3–8 s; vary shot size every 2–3 beats.

## Variation rule (so videos don't look copy-pasted)
Each new script gets: a **new key-colour story**, **new location set**, **new symbolic motif** for chapter cards, and a **new sequence of camera/pacing**. Only the characters + overall cut-out/gold folk style stay.

## Aspect ratios
- 16:9 (1920×1080) default. 9:16 (1080×1920) for Shorts: stack elements vertically, characters larger, subtitles in mid-lower third.
