# From Script to Visual – Method

## 1. Parse
- Identify **speaker/POV** (narrator, bhajan lyrics, katha, quiz/explainer).
- Identify **episode** (Bal Kand … Uttar Kand) and the **key characters**.
- Tag each sentence with: *place · time · characters · action · emotion (ras) · symbol*.

## 2. Beat-split
- Split at: change of place, change of speaker/emotion, new idea, list item, quote (shloka/chaupai).
- Target 3–8 s per beat (≈ 8–20 Hindi words at normal narration pace). Long sentences → 2 beats with a push-in or pan between.
- Mark **hero beats**: the 3–5 most emotional lines → close-up/special effects/music swell.

## 3. Map to visuals
| Script cue | Visual choice |
|---|---|
| Names a place | Establish it wide first (palace, forest, river, Lanka) |
| Quotes shloka/chaupai | Chapter-card style or Devanagari text on glowing background, character in prayer pose |
| Emotion: bhakti/shraddha | Hands folded, diyas, petals, halo, slow push-in |
| Emotion: dukh/viyog | Dusk, empty frames, lone figure, slow zoom out |
| Emotion: veer/yuddh | Wide battle rows, arrows, flags, camera shake *very light* |
| Dharma/lesson | Symbol on dark panel (lotus, bow, scale), calm text |
| Lists/numbers (explainer) | Counters, tick marks, 2-column layout (only if script is analytical) |
| Miracle (Setu, Sanjeevani, Virat roop) | Scale change, golden burst, rays, music swell |

## 4. Vary
- No two consecutive beats with same background + same shot size.
- Alternate: **Wide → Medium → Close → Symbolic insert**.
- Re-use a visual motif at start and end of video (bookend).

## 5. Assets list
After beats are done, extract unique: backgrounds, characters (+variants), props, effects, text cards → one asset list so they can be generated once and reused.

## 6. Timing
If audio exists, align beat start to spoken words (use word timestamps / SRT). If no audio, estimate 2.2–2.8 Hindi words/sec for devotional narration (slower for hero lines).

## 7. QA checklist
- [ ] Every character matches `characters.md`
- [ ] Every scene has a script line that justifies it
- [ ] Mood/colour matches ras
- [ ] Text spelled correctly (Devanagari ज्ञ, श्र, क्ष; conjuncts)
- [ ] Safe margins
- [ ] Bhakti rules passed
- [ ] Variety in shot size/pacing
