# AGENTS.md – Ramayan Bhakti Video Agent

This repo/folder contains a skill for designing visuals of **Ramayan / bhakti videos from a script**.

**Always start by reading `SKILL.md`**, then the files in `references/` and `templates/` as it directs.

Short version:
- Input = script. Output = beat-by-beat visual plan (shot list + image prompts).
- Characters are locked (`references/characters.md`); scenes/backgrounds/camera are designed fresh per script – never fixed.
- Style = flat 2D paper-cutout Indian folk art, gold ornaments, glowing devotional palette (`references/art-style.md`).
- Respect rules in `references/bhakti-rules.md` are mandatory.
